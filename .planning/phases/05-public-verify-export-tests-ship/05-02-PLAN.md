## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-05 | Information Disclosure | /verify page and API | mitigate | page uses getLedger/getVerify/getPublicSummary only, never getProject; smoke and db test assert token absent |
| T-05-06 | Information Disclosure | token in Referer/history | mitigate | verify page has no token; review page keeps no-referrer and links to /verify without the token |
| T-05-07 | Spoofing | forged receipt | mitigate | checkReceipt compares against the chain entries; not a proof of authorship, documented in README |
| T-05-08 | Tampering | malformed pasted JSON | mitigate | defensive shape validation, no eval, no throw |
| T-05-09 | Repudiation | actor name unauthenticated | accept | documented limit: actor is self-asserted |
</threat_model>
