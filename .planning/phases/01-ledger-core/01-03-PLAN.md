## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-01-06 | Tampering | concurrent appends forking chain | mitigate | `.immediate()` transaction reads head inside the lock; UNIQUE(project_id, idx) backstop; concurrency test |

| T-01-08 | Spoofing | guessable review token | mitigate | generateToken uses 256-bit randomBytes base64url |
| T-01-09 | Tampering | direct DB edit by privileged user | accept | Tamper-evident not tamper-proof; verify detects it, documented in README (Phase 5) |
