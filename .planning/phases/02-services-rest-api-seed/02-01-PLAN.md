## Phase Goal

**As a** agency owner, **I want to** create a project and have a client decide milestones through a private link, **so that** every decision is recorded once in a verifiable ledger.

Build the services layer and HTTP helpers on top of the Phase 1 `append`. Nothing in this plan touches `src/app`.

Purpose: all business rules (atomic create, IDOR check, decide-once mapping, DTO allow-lists, limiter) live here so route handlers (plan 02) and seed (plan 03) are thin.
Output: http helpers, zod schemas, DTOs, two services modules, a DB-backed test file.
</objective>
